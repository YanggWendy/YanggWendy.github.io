Research & Open Source

Agent Evaluation Infrastructure

Harbor Adapters & Harbor-Index

Benchmark adapters and parity validation that bring 80+ benchmarks and 22 agents onto one interface, reducing integration cost from O(mn) to O(m+n). I ran evaluations across 54 benchmarks and 6,627 tasks (~0.3M trajectories) and used a four-model, two-pass LLM-as-judge ensemble (96.3% unanimous agreement) to help curate the final hard-task set.

Python · Docker · Kubernetes · Cloud Sandboxes

Paper Code

GPU Communication Benchmark

CommBench

Built 101 executable tasks that test whether LLMs can write GPU communication code, drawn from NCCL, MSCCL++, NVSHMEM, DeepEP, vLLM, and SGLang. A cheat-resistant compile-run-validate harness runs on NVIDIA and AMD clusters (NVLink, InfiniBand/RDMA, RoCE). The strongest model reached competitive performance on only 30.7% of tasks.

CUDA · C++ · HIP · NCCL · NVLink · RDMA

Paper

Video Diffusion Inference

FastVideo

Contributed to a unified inference and post-training framework for accelerated diffusion-based video generation. I modularized data, configs, checkpointing, and sequence-parallel pipelines, and built version-gated CI and OIDC PyPI releases across 4 Python × 2 PyTorch × 3 CUDA versions.
